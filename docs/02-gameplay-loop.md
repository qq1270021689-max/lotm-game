## 2. 双层时间模型（本作最关键的玩法结构）

### 2.1 主动时间轴：花掉你的 24 小时

- 玩家每天拥有 24 小时预算，把**主动行动**排进时间轴（参考 `01-core-design.md` §2.3 行动时长表）。
- 行动以 1 小时为最小单位，顺序执行，逐小时结算文本。
- 未分配的小时默认按「闲逛/发呆」结算：少量恢复精力，触发街头随机事件。

### 2.2 后台倒计时槽：世界不等你

这是从密教模拟器继承的核心张力来源。**不占用主角时间、但随真实游戏时间流逝的倒计时槽**，同时最多挂 12 个（超出后新事件无法登记，制造取舍）：

| 倒计时槽示例 | 时长 | 到期效果 |
|---|---|---|
| 房租 | 7 天一周期 | 未付：被驱逐/抵押物品 |
| 委托期限 | 1–5 天 | 失败：黑市信誉下降、雇主反目 |
| 魔药调配中 | 1–3 天 | 材料已齐，药剂师正在调配 |
| 材料寄售中 | 2–7 天 | 售出得钱或流拍 |
| 隐秘集会 | 固定日期 22:00 | 错过等下期 |
| 消化度衰减预警 | 晋升后 30 天内未开始下一序列扮演 | 无碍，仅提示（长期不晋升者污染 +速 +20%） |
| 污染恶化 | COR ≥ 70 时启动 | 每 24h 触发一次失控前兆判定 |
| NPC 的个人事件 | 不定 | 「灰鼠」维克多 3 天后还债日、某 NPC 的婚礼、仇家上门 |
| 教会审查 | 每月一次 | 非凡者需准备身份掩护 |

**设计要点**：玩家的每一天都不是"今天做什么"的最优解，而是"倒计时们逼我先做什么"的权衡——这正是密教模拟器的乐趣内核。

## 3. 六大行动槽详表

每个行动槽 = **投入（小时 + 资源）→ 过程文本 → 产出 + 风险判定**。

### 3.1 打工 💼

- **投入**：4–10h；精力 −8/h。
- **内容**：当前职业的本职工作、加班、零工（码头搬运/誊写/侍应生）。
- **产出**：薪水（按职业线，§5.1）、职业技能经验、同事人脉事件。
- **风险**：工作事故（PHY 判定）、被同事发现非凡痕迹（CHA/伪装判定）。
- **扮演联动**：观众途径在客服/侍应岗扮演增速 +50%；占卜家在算命摊兼职视为扮演。

### 3.2 冒险 🗡️

- **投入**：4–8h（一个完整委托/探索）；精力 −20/h。
- **内容**：黑市委托、非凡事件调查、遗迹探索、护送/追猎。
- **产出**：金钱、非凡材料、情报、封印物线索、战斗经验。
- **风险**：受伤、SAN 损失、污染、死亡——**出发前可用占卜家/占星人能力预览风险等级**（途径差异化体验的关键）。
- **形式**：文字遭遇链（3–8 个连续事件节点，每节点给 2–4 个选择）。

### 3.3 休息·梦境 🛏️

- **投入**：1–8h。
- **内容**：小睡、正餐、整夜睡眠、冥想；非凡者追加「梦境」子行动——梦境占卜、入梦会客、梦魇审讯（不眠者/观众途径专属）。
- **产出**：精力、SAN 恢复；梦境子行动产出情报与扮演进度。
- **风险**：低 SAN 时睡眠触发噩梦事件；不眠者途径无睡眠项但需「静夜冥想」代替。

### 3.4 学习 📖

- **投入**：2–3h/次。
- **内容**：神秘学典籍、仪式魔法练习、职业技能进修、语言/历史等杂学。
- **产出**：知识卡（晋升/调配/仪式的前置）、SPI/MND 成长。
- **风险**：阅读禁忌典籍 +污染（好书都贵，禁书都要命）。
- **太吾式长线**：知识有熟练度，典籍需反复研读+实践，构成以月计的成长线。

### 3.5 社交 🍻

- **投入**：1–2h/次拜访。
- **内容**：拜访 NPC、酒馆闲聊、参加集会、送礼、委托中介。
- **产出**：好感/信任、情报卡、委托、人脉卡（§3.7）。
- **风险**：说错话（对话选择）、被卷入 NPC 的麻烦、身份暴露。
- **硬规则**：NPC 只在作息表对应时段可交互（`01-core-design.md` §2.5）。

### 3.6 扮演 🎭（非凡者核心槽）

- **投入**：1–4h。
- **内容**：执行当前序列的扮演守则行为（占卜、行医、狩猎、守夜、表演戏法……）。
- **产出**：消化度（晋升的唯一硬通货）、少量金钱/声望。
- **风险**：扮演过火被教会/同途径者注意；错误扮演 +污染。
- **设计要点**：扮演行为要尽量"寄生"在其他槽里——打工即扮演（心理医生坐诊）、社交即扮演（读心）、冒险即扮演（猎人追踪），让途径选择真正改变所有槽的体验。

### 3.7 资源体系（卡牌逻辑，文字呈现）

所有可持有物统一为五类「资源」，界面是一列文字清单而非牌堆：

| 资源类 | 例子 | 产出槽 | 消耗于 |
|---|---|---|---|
| 金钱 | 镑/苏勒/便士 | 打工、冒险、寄售 | 生活、材料、学习、贿赂 |
| 物品/材料 | 拉瓦章鱼血液、子弹、封印物 | 冒险、黑市 | 魔药、装备、送礼 |
| 情报 | 「码头失踪案」「值夜者巡逻路线」 | 社交、冒险、梦境 | 解锁行动选项、委托完成 |
| 人脉 | 「灰鼠的渠道」「值夜者的好感」 | 社交 | 行动加成、特殊商店、保命 |
| 知识 | 《秘密之书》研读度、仪式魔法 | 学习 | 晋升、调配、新行动解锁 |

资源之间存在**转化链**（密教式的核心乐趣）：情报 → 委托 → 材料 → 魔药 → 晋升；人脉 → 渠道 → 稀缺材料……

## 4. 压迫循环（密教式生存压力）

四股压力周期性袭来，玩家永远在"还哪一笔债"之间选择：

1. **经济压力**：每周房租日 + 每日饭钱。破产 → 失去住所（睡眠恢复减半）→ 露宿事件链。
2. **精神压力**：SAN 低于 30 → 幻觉事件；到 0 → 精神崩溃结局线。
3. **污染压力**：非凡行为的隐藏税。COR 过 70 → 失控前兆倒计时启动（§2.2）。
4. **社会压力**：教会审查（每月）、帮派逼债、雇主催工——来自 NPC 作息表与个人事件的定向压力。

**压迫循环与成长的对价**：想快晋升就要多冒险/多扮演 → 污染与树敌涨得快；想过安稳日子打工攒钱 → 材料买不起、集会融不进。两个极端都可玩（凡人线也是一种通关），中间态最难——这是设计上的刻意张力。

## 5. 长期人生模拟（太吾式沙盒）

### 5.1 凡人职业线（与非凡线并行）

电报局职员→局长；码头工→工头→承包商；诊所助手→执业医师……职业有晋升考核（技能+人脉+金钱），提供稳定收入与社会身份掩护。**非凡身份越深，越需要一份体面的凡人工作当面具**——双线经营是中年段玩法核心。

### 5.2 生活资产

住所升级（合租阁楼→独栋→带地下室的宅邸——地下室解锁私下仪式/关押/调配）、家具、仆役、婚姻（与 NPC 关系满级可组建家庭，配偶有自己的作息与秘密）。

### 5.3 世界每日推进（00:00 结算）

- NPC 际遇掷骰：升迁、破产、恋爱、暴毙、失控成怪物（他死了，特性析出进总账——你明天可能在黑市看到熟人的特性挂牌）。
- 委托板刷新、物价按特性总账浮动、报纸头条（重大事件的世界反馈）。
- 这部分是纯后台模拟+晨间报纸/流言呈现，太吾"过月看天下事"的日制版。

### 5.4 死亡与继承

- 主角死亡/失控 → 本周目结算（一份"生平报告"，密教式碎片文本回顾）。
- 新周目彩蛋：**你上一世析出的非凡特性进入了总账**，可能在新周目的黑市、教会武库、甚至新角色的魔药里与你重逢。特性守恒在此与多周目叙事闭环。

## 6. 单日玩法实录（示例，呈现游戏"手感"）

> 第 14 天 · 周二 · 序列9 占卜家 · 现金 1 镑 4 苏勒
>
> **06:30 醒来**。精力 82/100。枕边的灵摆微微发烫——昨晚的梦境占卜显示今日「冒险：凶」。你决定听劝。
>
> **07:00–08:00 早餐**（−2 便士）。房东太太敲门：【房租倒计时：3 天，需 1 镑】。
>
> **08:00–12:00 打工**（电报局，+4 苏勒）。同事压低声音：码头又失踪了两个人。（获得情报卡「码头失踪案」）
>
> **12:00–13:00 午餐**。你把情报卡在心里过了一遍——黑市委托板上那条"查码头"的活，报酬 15 苏勒，【期限：2 天】。
>
> **13:00–17:00 打工**（+4 苏勒）。今天的电报量出奇地大，多半与失踪案有关。
>
> **18:00–20:00 扮演**：在「醉水手」酒馆摆占卜摊（消化度 61%→65%，小费 +9 便士）。一个生面孔问："能占寻人吗？"——触发事件【生面孔的委托】。
>
> **20:00–22:00 社交**：陪「灰鼠」维克多喝了两杯（好感 +4）。他透露后天有一批"章鱼血"到货。（人脉卡「灰鼠的渠道」进度 +1）
>
> **22:30 梦境占卜**：针对码头委托——画面里全是浓雾和钟声。风险评级：**凶**。你咽了口唾沫，决定明天先去黑市买情报再定。
>
> **23:00 入睡**。【后台倒计时】房租·3天 / 码头委托·2天 / 章鱼血到货·2天 / 教会审查·17天。污染 11/100，缓慢而安静。

## 7. 文字版界面布局（无图形资产要求）

```
┌─────────────────────────────────────────────┐
│ 第14天 周二 08:00 | 精力82 SAN74 污染11 | 1镑4苏勒 │
├─────────────────────────────────────────────┤
│ 【正在发生】（后台倒计时槽，最多12个）            │
│  ▸ 房租 3天 ▸ 码头委托 2天 ▸ 教会审查 17天 …     │
├─────────────────────────────────────────────┤
│ 【此刻】叙事文本区（逐小时结算文本流）             │
│  …电报局的日子一成不变。同事压低声音……          │
├─────────────────────────────────────────────┤
│ 【下一步行动】                                  │
│  打工(4h) 冒险(4-8h) 休息(1-8h) 学习(2h)        │
│  社交(1-2h) 扮演(1-4h) 闲逛                      │
├─────────────────────────────────────────────┤
│ 【持有】金钱·物品·情报·人脉·知识（可展开清单）      │
```
